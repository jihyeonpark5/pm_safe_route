# 1차 개선: 위험 노출 지표와 RS 검증

기준 소스: `0959e7be6638ef33450b632dc97c73d9e3064820`.
2026-10-28 실행. 기존 최적화 목적함수와 학습된 도로 RS는 그대로 두고,
경로 평가 지표와 검증 절차를 개선했다. 아래 결과는 실제 사고 감소율이 아니다.

## 변경 내용

- `13_optimize_route_ortools.py`의 CSV에 거리·시간 기준 위험 노출과 고위험 통과거리·시간을 추가했다.
- `14_validate_risk_score.py`에서 로지스틱 예측과 파생 RS를 각각 평가한다.
  원시 변수의 Min-Max 정규화, 표준화, 회귀 학습, RS 가중치 산출 모두 학습 fold 안에서 수행한다.
- `15_compare_report_routes.py`에서 고정 좌표로 3개 사례를 재계산하고, 각 경로의 edge 목록을 저장한다.
- 기존 모델 스크립트의 학습 데이터 성능 출력에 재대입 평가임을 명시했다.

## 지표 정의

| 열 | 정의 | 단위/해석 |
|---|---|---|
| `exposure_sum` | Σ RS_e | 기존 edge 단순 합계. 분할에 민감함 |
| `risk_sum` | Σ [(RS_e/100) × t_e + 등급별 고정 비용] | 기존 최적화 위험 비용. 노출 합계와 다름 |
| `distance_exposure_m` | Σ (RS_e/100) × L_e | 위험 점수로 가중한 거리 지수 |
| `time_exposure_sec` | Σ (RS_e/100) × t_e | 위험 점수로 가중한 시간 지수 |
| `distance_weighted_rs` | Σ RS_e × L_e / Σ L_e | 거리 가중 평균 RS |
| `high_risk_distance_m` | 고위험 edge의 길이 합 | m |
| `high_risk_time_sec` | 고위험 edge의 통과시간 합 | 초 |
| `high_risk_distance_ratio` | 고위험 거리 / 전체 거리 | 0~1 |

새 거리·시간 지표는 같은 RS와 속도를 가진 도로를 여러 edge로 나눠도 동일하다.
새 지표 이름 뒤의 `_reduction_vs_lambda0`는 `1 - 현재값 / λ=0 값`이다.
음수는 노출 증가, 양수는 감소이며 기준값이 0이면 비교율은 결측값으로 둔다.
고위험 지표는 기존 edge 대표등급을 사용하므로, 짧은 고위험 격자를 정확히 분할한 결과는 아니다.

## 모델 검증 결과

도로 정보가 있는 10,852개 격자 중 사고 발생 격자는 259개(2.39%)다.
아래는 5-fold 지표의 평균이며 괄호는 fold 간 표준편차다.

| 분할 | 점수 | ROC-AUC | Average precision | 상위 10% 사고 포착률 |
|---|---|---:|---:|---:|
| 무작위 층화 | 파생 RS | 0.7396 (0.0363) | 0.0573 | 26.7% |
| 무작위 층화 | 로지스틱 | 0.7866 (0.0260) | 0.0802 | 35.9% |
| 1km 공간 블록 | 파생 RS | 0.7370 (0.0540) | 0.0601 | 25.7% |
| 1km 공간 블록 | 로지스틱 | 0.7822 (0.0436) | 0.0811 | 33.9% |

원래 보고서의 약 0.79는 로지스틱 성능이며, 파생 RS에 그대로 적용할 수 없다.
로지스틱 예측값은 RS보다 높은 순위 판별력을 보였지만, 이것만으로 로지스틱 예측값을
시간대별 사고 확률이나 경로 사고 확률로 사용할 수는 없다.
balanced 학습의 확률 보정과 독립 검증이 추가로 필요하다.

공간 분할은 EPSG:5179 기준 고정 1km 블록을 StratifiedGroupKFold로 나눈다.
같은 블록은 학습·평가에 중복되지 않지만 인접 블록 사이의 완충구역은 없으며,
블록 크기 민감도·미래 연도·외부 지역 검증은 이번 결과에 포함되지 않는다.
상위 10%는 각 평가 fold에서 ceil(0.1 × 격자수)개를 선정하고 동점은 grid_id로 해소했다.
점수 계산에는 해당 평가 격자의 사고 정답을 사용하지 않는다.
RS 검증은 3개 시간대 보행자 정규화값의 평균을 사용한 격자 수준 평가다.
시간대별 사고자료가 없어 시간별 RS 정확도는 검증하지 못했다.

## 기존 3개 경로 재평가

18시·S1, 현재 저장소 목적함수의 λ=0 대비 λ=1 변화다.
아래 표는 변화율이므로 **+는 증가**, **-는 감소**다.

| 사례 | 이동시간 | 기존 RS 단순 합계 | 거리 기준 위험 노출 | 시간 기준 위험 노출 | 고위험 통과거리 |
|---|---:|---:|---:|---:|---:|
| 1: 저장소 논현역→선릉역 좌표 | 8.96→9.54분 | -13.1% | +3.8% | +0.9% | 76.7→76.7m |
| 2: 역삼1동→강남구민회관 원본 좌표 | 10.97→12.01분 | -10.4% | +11.0% | +12.7% | 54.1→54.1m |
| 3: 일원1동→대치2동 | 19.09→22.04분 | -14.7% | +11.0% | +3.2% | 2,375.4→2,197.4m |

λ=0.5에서는 사례 1의 거리·시간 노출이 각각 1.0%, 3.8% 감소했다.
사례 2와 3에서는 λ=0.5도 두 노출 지표가 모두 증가했다.
따라서 기존 지표 감소를 모든 경로의 안전성 향상으로 일반화할 수 없다.

원본과의 대응에 다음 주의가 필요하다.

1. 발표자료 사례 1은 '신논현역'으로 표시되지만 저장소 캐시와 reportfinal CSV는 '논현역'이다.
   이번 실행은 캐시의 `(127.0231433, 37.5072398)`을 고정했다.
   보고서의 사례 1 숫자와 완전히 같은 실험이라고 단정하지 않는다.
2. 사례 2는 원본 reportfinal CSV에 기록된 `(127.0335, 37.4957)`과
   `(127.0625, 37.4969)`를 그대로 사용했다. 장소명 기반 지오코딩을 새로 수행하지 않았다.
3. 사례 3의 발표 값 1,922.19→1,317.58은 `risk_sum`에 해당한다.
   같은 경로의 RS 단순 합계는 947.88→808.86이다. 기존 자료에서 두 지표를 혼용하지 않아야 한다.
4. λ=0에도 쾌적성·회전 비용이 포함된다. 위 표의 기준은 순수 최단시간 경로가 아니다.
5. 결과의 Optimal은 선택된 부분 그래프 안의 목적함수 최적값이다.
   실패 시 전체 그래프 재시도 기능은 전체 그래프 최적성과의 동등성을 증명하지 않는다.

## 재현 방법

원본 저장소의 원시·가공 데이터가 있는 프로젝트 루트에서 실행한다.

```bash
pip install -r requirements-validation.txt
python scripts/14_validate_risk_score.py
python scripts/15_compare_report_routes.py
python -m pytest -q
```

`data/output/validation_v1/`에 검증 요약, fold별 성능·계수,
OOF 예측, 경로 비교, 경로 edge 목록, 입력 SHA-256과 실험 설정이 저장된다.
OOF 예측 전체 파일은 실행 시 생성하며 PR에는 요약과 재현 가능한 코드를 포함한다.
`tests/`에는 도로 분할 불변성, 유효하지 않은 입력 거부, test 데이터에 의한 학습 오염 방지,
OOF 전체 격자 커버리지·공간 블록 분리, 동점 처리 검증이 있다. 실행 결과 8개 통과.
