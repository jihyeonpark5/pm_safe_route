# 2차 개선: 추가시간 상한 안에서 위험 노출 최소화

기준: PR #1의 `5a2f213b8a9a69ed96446ad33a6b63eca3e5a5a7`.
2026-10-28 실행. 기존 RS를 유지하고, 경로 선택 목적함수와 기준 경로를 개선했다.
아래 개선율은 모델상 위험 노출 지수에 대한 값이며 실제 사고 감소율이 아니다.

## 무엇을 구현했는가

사용자가 허용한 추가시간 안에서 거리 기준 위험 노출이 가장 작은 경로를 찾는다.

```
minimize  Σ (RS_e / 100) × length_e
subject to Σ time_e <= T_fastest + min(0.10 × T_fastest, 120 seconds)
```

기본 설정은 최단시간의 10%와 2분 중 더 짧은 상한을 사용한다.
`--budget-mode ratio`는 비율만, `--budget-mode seconds`는 초 단위 상한만 적용한다.
최단시간은 전체 방향성 그래프에서 edge 이동시간 합을 직접 최소화해 계산한다.
기존 λ=0은 시간비용의 정규화·상단 clipping, 쾌적성·회전 비용을 포함하므로 순수 최단시간이 아니다.

- `scripts/time_budget_routing.py`: 시간·노출 Pareto label 기반 제약 최적화.
- `scripts/16_compare_time_budget_routes.py`: 기존 3개 사례 또는 사용자 좌표에 대해
  순수 최단시간, 기존 λ=0/0.5/1, 새 경로를 같은 기준으로 비교한다.
- 결과 CSV, 경로별 edge 목록, EPSG:4326 GeoJSON, 입력 해시와 실험 설정을 저장한다.
- 90도 이상·150도 이상 방향 전환 수를 함께 기록해 회전 비용 제외의 영향을 드러낸다.

## 알고리즘과 최적성 표시

전체 35,455개 방향성 arc를 대상으로 같은 노드까지 도달하는 시간·노출을 보존한다.
한 경로가 다른 경로보다 시간과 노출 모두 크거나 같으면 그 label은 제거한다.
목적지까지의 최단시간과 최소노출 하한을 역방향 Dijkstra로 구해, 시간 상한을 초과하거나
현재 확보한 경로의 노출을 개선할 수 없는 label을 가지치기한다.
시간을 정수 구간으로 반올림하지 않으며, λ 가중합 경로 후보만으로 해를 제한하지 않는다.

- `optimal`: 전체 입력 그래프의 시간 제약 아래에서 최적 노출을 확인했다.
  가지치기의 절대 수치 허용오차는 노출 지수 1e-9다.
- `feasible_limit`: label 수 또는 실행시간 한도에 도달했다. 현재 확보한 시간 제약 충족 경로와
  노출 하한, `relative_gap`을 반환한다. 최적해로 표시하지 않는다.
- 시간 제한은 최단경로 하한 준비 후 label 탐색에서 확인하는 soft limit이다.
  그래프 로딩·비용 준비까지 포함한 서비스 응답시간 제한은 아니다.
- 최단시간 경로를 최초 후보로 유지하므로, 반환하는 새 경로의 거리 기준 노출은
  그 기준 경로보다 커지지 않는다. 시간 기준 노출의 동시 감소까지 보장하지는 않는다.

이 문제는 최악의 경우 label 수가 크게 증가할 수 있다. 기본 한도는 100만 label과 60초이며,
한도에 도달한 결과는 실제 gap을 확인한 뒤 사용해야 한다.

## 3개 사례 결과: 순수 최단시간 대비

18시·S1, 추가시간 상한 `min(10%, 120초)`. 3개 새 경로 모두 `optimal`, 상한 충족이다.

| 사례 | 최단시간 | 새 경로 시간 | 추가시간 | 거리 기준 노출 변화 | 시간 기준 노출 변화 |
|---|---:|---:|---:|---:|---:|
| 1: 저장소 논현역→선릉역 | 8.57분 | 9.02분 | +26.93초 | -2.83% | +0.77% |
| 2: 역삼1동→강남구민회관 원본 좌표 | 10.87분 | 10.87분 | +0.01초 | -0.25% | -0.23% |
| 3: 일원1동→대치2동 | 13.00분 | 13.25분 | +14.68초 | -0.88% | +0.02% |

표에서 음수는 노출 감소, 양수는 증가다. CSV의 `_reduction_vs_fastest` 열은
`1 - 현재 / 기준`으로 정의하므로 부호 방향이 표의 변화율과 반대다.
초 단위의 작은 차이는 일정 속도를 가정한 계산값이며 실제 주행 정밀도를 뜻하지 않는다.

고위험 통과거리는 사례 1/2에서 각각 76.7m/54.1m로 동일하고,
사례 3에서는 최단시간 경로 181.3m에서 새 경로 167.2m로 줄었다.
사례 1은 90도 이상 방향 전환이 최단시간의 5회에서 새 경로의 8회로 늘었다.
거리 기준 노출이 줄더라도 회전 편의성과 시간 기준 노출이 함께 좋아지는 것은 아니다.

## 기존 λ=1 경로와 비교

| 사례 | 기존 λ=1 시간 | 새 경로 시간 | 기존 λ=1 대비 거리 기준 노출 감소 |
|---|---:|---:|---:|
| 1 | 9.54분 | 9.02분 | 5.63% |
| 2 | 12.01분 | 10.87분 | 11.94% |
| 3 | 22.04분 | 13.25분 | 39.72% |

기존 λ=1 경로는 세 사례 모두 새 기본 시간 상한을 초과했다.
이 표의 차이에는 목적함수 변경, 전체 그래프 사용, 회전·쾌적성 비용 제외가 함께 작용한다.
개별 변경 하나만의 효과로 해석할 수 없으며, 순수 최단시간 기준의 개선폭과 구분해야 한다.
특히 사례 3의 큰 차이를 '사고 위험 39.72% 감소'로 해석하면 안 된다.

## 실행 방법

```bash
pip install -r requirements-validation.txt

# 기본: 3개 사례, 18시 S1, min(10%, 120초)
python scripts/16_compare_time_budget_routes.py

# 비율만 또는 초 단위 상한만 사용
python scripts/16_compare_time_budget_routes.py --budget-mode ratio --max-extra-ratio 0.1 --output-dir data/output/v2_ratio
python scripts/16_compare_time_budget_routes.py --budget-mode seconds --max-extra-seconds 120 --output-dir data/output/v2_seconds

# 좌표는 경도,위도 순서. 두 좌표를 모두 제공한다.
python scripts/16_compare_time_budget_routes.py --start-coords 127.0335,37.4957 --end-coords 127.0625,37.4969 --hour 18h --scenario S1 --output-dir data/output/v2_custom

# 한도 도달 시 feasible_limit과 gap을 확인한다.
python scripts/16_compare_time_budget_routes.py --max-labels 100000 --max-runtime-sec 30

python -m pytest -q
```

기본 결과는 `data/output/validation_v2/`에 있다.
`route_comparison.csv`에는 공통 최단시간 대비 노출 변화, 추가시간, 시간 상한 충족 여부,
회전 수, 최적성 범위 및 gap을 저장한다. `route_segments.csv`에서 경로를 재구성하고,
`routes.geojson`에서 지도로 확인할 수 있다. `metadata.json`에 좌표·입력 해시·제약 설정이 있다.
고정 120초만 허용한 별도 실행에서도 이번 세 사례의 새 경로는 동일했다.

## 검증과 남은 한계

테스트 총 36개 통과. 새 검증에는 작은 순환 그래프의 모든 단순 경로를 열거한 참값과의 비교,
λ 가중합으로 찾을 수 없는 제약 최적해, 시간 상한 경계, 단방향 연결, 0점수 순환,
도로 분할 불변성, 탐색 한도·실행시간 종료의 상태와 하한 검증이 포함된다.
실데이터 3개 사례의 기본·120초 설정 및 같은 출발·도착 좌표 입력도 실행했다.

이번 단계에서 RS 모델·속도 시나리오·도로 허용 여부는 갱신하지 않았다.
이동시간은 edge 길이/속도의 합이며 신호대기, 회전 지연, 가감속, 출발·도착 접근시간을 제외한다.
새 알고리즘은 쾌적성 비용과 회전 패널티를 목적함수에 넣지 않는다.
원시 도로망에 없는 회전 금지와 접근 제한을 추가로 판정하지 않는다.
기존 edge 대표 위험등급을 사용하므로 짧은 고위험 격자 구간이 평균에 묻히는 한계도 남는다.

사례 1은 발표자료의 '신논현역' 표기와 다른 저장소 '논현역' 좌표를 그대로 사용했고,
사례 2도 원본 CSV 좌표를 유지했다. 세 사례 결과만으로 지역 전체 성능을 일반화할 수 없다.
다음 검증은 다수 출발·도착 쌍, 여러 시간대·속도 시나리오, 회전·신호 지연 반영과
독립 사고 데이터 확인이다. 거리 노출과 시간 노출을 동시에 악화시키지 않는 추가 제약도
별도 비교 대상으로 남긴다.
